How it works:
Preserve Text mode — uses pdf-lib to rewrite the PDF without its restriction flags. The original text, fonts, vectors and structure stay 100% intact and remain editable in any PDF editor.
Image PDF mode — rasterises each page (the original behaviour). Use this only when the source PDF is heavily encrypted and Preserve Text mode fails.

Works for PDFs with owner/permission passwords (copy/print/edit restrictions) but not for PDFs that require a password to open. All processing happens in your browser — no files are uploaded.
