What is Normal.dotm?
It is MS Word's global scratchpad template. When you record a macro, edit a shortcut key, or customize your ribbon layout, Word saves those changes to this file. Exporting from Word or uploading your old system's Normal.dotm allows you to carry over all those settings.

VBA Project Password Protection Settings

How to apply manually on other PCs

If you are not using the desktop application, or want to install it on another computer:
  1. Click the Download button on the uploaded file above to save it. If the template contains ribbon custom UI, also click Download UI to download the Word.officeUI file.
  2. Close Microsoft Word completely.
  3. Restore Template (Macros & Shortcuts): Open File Explorer, enter %APPDATA%\Microsoft\Templates in the address bar, backup the existing Normal.dotm, and replace it with the downloaded template file (renaming it to Normal.dotm).
  4. Restore Ribbon/Taskbar UI (if downloaded): Open File Explorer, enter %LOCALAPPDATA%\Microsoft\Office in the address bar, backup the existing Word.officeUI, and replace it with the downloaded UI file (renaming it exactly to Word.officeUI).
  5. Open Microsoft Word; all your macros, shortcuts, custom ribbon tabs, and taskbar buttons will be fully active!

Troubleshooting: Macros Not Loading?

If you click import but MS Word still does not load your macros or ribbon tabs, check these common issues:
  • Macro Security Level: Microsoft Word blocks macros by default. In Word, go to File > Options > Trust Center > Trust Center Settings... > Macro Settings, and select "Disable all macros with notification".
  • Windows File Block (Mark of the Web): Windows blocks files downloaded from the web. Close Word, go to %APPDATA%\Microsoft\Templates, right-click on Normal.dotm, click Properties, and check the Unblock checkbox at the bottom of the General tab, then click Apply.
  • Ribbon UI Customization Locked: If MS Word was open in the background while importing, the Word.officeUI file or Normal.dotm template might have been locked or overwritten by Word. Close Word completely and click **Import & Replace** again.
